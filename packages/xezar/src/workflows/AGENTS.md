# Guidance for `packages/xezar/src/workflows/`

These rules are the full task-routing guidance moved from the repository root. Root `AGENTS.md` retains the routing index and canonical cross-repository rules.

## Workflows (YAML chains, steps, retries)

A step is agent (`prompt`/`skill`) XOR check (`command`); a file has `steps` XOR the portable `skills` shorthand — both enforced by zod refinements. `onFail.retry` may only reference an _earlier_ step (`stepsIssue`). `{{task}}` is the substitution token. `quick-task` is the built-in zero-config workflow; built-ins always come back after delete. An agent step may set its own wall clock with `timeout` (#22) — the literal `none`, or a positive duration in `s`, `m` or `h` (`45s`, `90m`, `2h`) — resolved in one place, `stepTimeoutMs`; a check step may not carry it. An **absent** `timeout` is a protected default, not an unset value: the last (interactive) step stays uncapped and every earlier agent step falls through to the runner's 30-minute `DEFAULT_RUN_TIMEOUT_MS`, and changing that is a break (`BACKWARD_COMPATIBILITY.md` §4). An earlier agent step is `done` only when its last turn ends with `XEZ:DONE` (#317, `unfinishedStepReason`): it runs one turn and cannot wait for an answer, so a question, `XEZ:MONITORING` or plain prose fails it and stops the run instead of carrying on; the last step keeps its interactive rules (`BACKWARD_COMPATIBILITY.md` §8). The FIRST automatic `onFail` return re-enters the retry target by resuming that step's own recorded backend session and sending it only the failing output — the brief is not repeated (#676); the second return is the fresh session with the whole brief it has always been, an unreachable session falls back to a fresh spawn inside the same return with a `note` and no extra attempt — no recorded id, another backend, another agent account, a backend whose runner cannot resume at all (OpenCode) or a resume the backend refuses at runtime before the model said a word, and `onFail.max` and the terminal "after N attempts" message are untouched.
