At 375 px

The same page as the pane, framed at 375 px. The desktop header and the section nav go (the mobile top bar names the page and the settings pills replace the nav, as today). The agents were already stacked, so nothing re-flows into a new layout: rows wrap, and every action becomes a 44 px target.

  • Cut first: the agent’s version number, then “Check again”, which moves into Show details. Both are facts a person looks for on purpose, not while scanning.
  • Never cut: an account’s name (or “Name hidden”), the “In use” marker, the login state word, a problem sentence and its fix, and the import block’s sentence and button.
  • Full width: “Copy 3 accounts”, “Use the built-in login” and “Add account” – one clear thing to press per block.
  • Paths wrap at any character rather than truncating, so a long folder never pushes the page sideways.
