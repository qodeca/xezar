The limits chip

The smallest honest answer to “can my logins work now?”, visible on every page. On a desktop it is a band above the sidebar footer, because the cockpit has no desktop top bar; on a phone it sits in the top bar’s status slot. It is a button: it opens a Popover with the per-agent sentence and the logins that are out or unknown, and a link to Settings → Agent accounts. It never starts a check and never acts on a login.

Desktop – the sidebar band

1 · Some logins out (the default case of this mockup) – expanded

One segment per agent that applies, each with its own dot: success when every login of that agent can work, pending when some cannot, danger when none can. The counts are “can work / all logins of that agent”, the server’s canWork and total. Pressing the chip opens this Popover; it lists only the logins that are not plainly fine, so the good news stays short. Escape closes it and returns focus to the chip.
