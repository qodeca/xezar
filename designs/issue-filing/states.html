Every state

Each state has its own sentence. No state is carried by colour, by an icon or by a spinner alone. Every one of them keeps whatever the person has already typed.

1. The dialog, before anything is typed

2. The skill is not installed here

The control is never hidden for this reason: hiding it would make a missing capability look like a missing feature, and a person would go looking for a button that does exist. The dialog opens, the brief is collected exactly as before, and one sentence names the capability that is absent and what is lost with it. Nothing is installed, downloaded or written by this screen.

3. Hosted mode, and the two ways GitHub is absent

4. Loading, and the tab itself failing

5. The start itself failing

A failed POST /runs never closes the dialog and never clears the box. The message is the server's, and the brief is still there to retry or to copy out.

6. The running draft, from the tab

7. The question itself, in the task thread
