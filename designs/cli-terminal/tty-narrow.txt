# Stalled is advisory; blocked is a fact. The 3-line cut removes the end of
# the stall summary, where it says nothing was stopped, so “still running —
# nothing was stopped” is its own line and is always printed, like the URL

# “needs you”.
# The verdict line keeps the reviewer’s own word in full. The long commit
# id does not fit beside it, so it wraps to its own line and is cut with ….
# The plain line keeps the whole summary (non-tty.txt).
