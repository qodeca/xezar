7. The rhythm scale

Six named distances – 8 / 12 / 16 / 20 / 24 / 32, the scale Carbon, Radix and Atlassian share – all multiples of the one spacing unit, so the density select scales them. A file uses a token between blocks and the numeric scale inside a control – never a hand-typed pixel.

What to look for

  • In every pair the text is the same size. Only the air changed.
  • Switch the bar to Compact for real: today’s column tightens unevenly (nav rows, tool rows, the table header and the buttons stay put); the proposed column tightens as one piece.
  • Switch to Roomy: the proposed fourth density, 5 px per unit (+25 %, the mirror of Compact for real). Opt-in; the default stays Comfortable. Every density scales the whole page as one piece.
  • The table does not grow. If you want it to, that is decision D-2 in the README.
