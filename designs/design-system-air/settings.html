Default runner

Preselected for new tasks in THIS repo, and used by the chain planner. Each task can still pick another runner.

Default models

The model preselected in the composer for each runner. Auto lets the runner decide per task.

System prompt

Extra instructions appended to every run, whichever runner executes it. This is the only place it is edited.

Leave empty and save to clear. Applied to new runs only.

20,412 characters — the limit is 20,000.

Live title updates

Refresh a task's short title through the namer model as the run progresses. A manual rename always wins and stops updates for that task.

Review changes before finishing

When on, a task with changes pauses so you can Accept, Send back, or open a Draft PR. Autonomous tasks always skip this and finish on their own. Default: off — tasks finish without asking.

Planner and namer models

Two small background jobs: the planner turns a task into a chain of steps, the namer gives it its display title. Both are Claude aliases and are ignored when this project's default agent is not Claude.

Team skill repositories

Extra skill playbooks pulled from git, one per line: owner/name, a git URL, or a local path — add @branch for a ref other than main. This project's own .xezar/skills always wins. Leave empty to use no team skills.

Base branch

New task worktrees branch from this and draft PRs target it. Also settable from the Git view.

Theme

System follows your OS preference. Applies to this browser.

Accent

The primary action color. Saved with this repo's cockpit state.

Density

Compact tightens spacing across the cockpit — text stays the same size.

Roomy adds space between things and the Compact options take it away — text stays the same size.

Reading width

Wide lets a task's session and commits use more of the screen. Narrow keeps a comfortable reading column. The Changes tab is always full-width.

Agent accounts

Agent accounts are managed from the machine that owns the checkout — this cockpit runs in hosted mode.
