## 3. Rules that go with the map

1. **Claude is the scarce quota.** Do not dispatch Claude by default; use it for cockpit UI work and as the fallback when Codex is unavailable. After a "session limit" failure: `cancel_auto_resume` on every failed run, re-dispatch on Codex or pi, and do not let the 5-hour reset re-run the same work twice. If `execution_control continue` is used after an account switch, verify the whole chain resumed: on 2026-09-15 it resumed only the agent step for one run, leaving a `done` run with commits but no push, PR, or gates; this is engine behaviour, not a Claude-model verdict (leader log, run `cedba1c1`).
2. **Astra for every task that must generate an image** (mockup renders, diagrams, graphics), whatever its size – owner rule 2026-09-16 09:53. Otherwise **astra only when the task is genuinely hard**: several verdicts at once, large multi-surface implementations, kit refactors, security-sensitive reviews. Everything procedural goes to terra, everything judgement-heavy to sol, everything mechanical to luna. Use the lowest reasoning effort that produces the result.
3. **`gpt-5.5` retires 2026-10-14** – stop using it now; sol replaces it.
4. **OpenCode is out** (8/8 stalls with both local models). Only re-trial on the owner's request, one small read-only task, cancel at 15 min without events. The owner keeps OpenCode out until the cockpit runs 0.16.0.
5. **pi briefs are one-shot**: one deliverable, one comment, "post once and stop". DeepSeek posted a comment twice once; Qwen looped for 2 400 events after its comment.
6. **Local models never touch a branch**: no implementation, no QA on the live harness, no security reading. Read-only verdicts, triage, tracker updates, bounded single-file test fixes at most.
7. **Terra integration briefs use explicit ALLOWED actions, never conditions.** For example, say to run `gh api -X PATCH … -f base=main` regardless of `mergeStateStatus`; never permit `gh pr update-branch` in an exact-head brief. Conditional wording led to an integration skip on #511 and an exact-head refusal after `update-branch` moved #510's head (see §5).
8. **Codex wording**: "the kit's checks read the primary checkout by design – allowed; never run a git command of your own that writes to that primary checkout". Codex reads "never git in primary" literally and BLOCKs.
9. **Do not change a runner default model from the cockpit while the kit is in use.** Set it per task, or land the committed pin through a PR first. The cockpit write to the primary `.xezar/config.json` made kit bootstrap reject its snapshot; `quick-task` with a `xezar-*` skill avoided that kit step (see §5).
10. **Pull the primary before every dispatch after a merge**: a worktree cut from an `origin/main` that is ahead of the primary fails the kit bootstrap step ("existing task asset differs") – seen 2026-09-15 21:58 and 2026-09-16 09:43.
11. **Rotate and record**: every stall, wrong fact or "stopped after diagnosis" goes into the campaign note and, if it changes a row here, into this file and memory `xezar-codex-model-tiers` / `xezar-model-trust-rule`.
12. **Backup lane, owner rule 2026-09-18 (exact words): "Keep DeepSeek V4.1 and Pi as a backup for situation that there will be no limits available on GPT and Claude accounts you have access to. Save this rule to documentation."** `deepseek-api/deepseek-flash` on pi is the BACKUP lane: dispatch it only when no Claude account and no Codex quota is available. Read-only work first (triage, review, tracker filing, record re-checks); nothing it writes merges without a Claude review; every Major claim it raises is verified by Opus before it reaches the owner.
13. **`mac-m4/ornith-1.5-35b-a3b-mlx` was trialled and DROPPED by the owner, 2026-09-18** (7 PASS, 1 PARTIAL, 2 FAIL of 10 in the fixed-task benchmark, one FAIL being work in the primary checkout instead of its worktree) – do not dispatch it. The same 2026-09-18 benchmark scored local `dgx-spark/deepseek-v4-flash-vision` on pi 10 of 10 PASS at 2–90 minutes, which is why it stays the default local read-only lane alongside rule 12's cloud backup lane.
