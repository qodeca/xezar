### 2026-09-23 — a completed turn is not a completed headless process

- A real Codex 0.155.1 denial reached `turn.completed`, then the headless CLI exited normally with status 0 after 22.2 seconds. A QA window shorter than the runner's bounded EOF/watchdog path can misclassify that interval as a hang; live QA should wait for the CLI result or record the exact observation bound.
