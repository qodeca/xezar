### 2026-09-20 — the kit's red-proof recipe named a shared resource, and a contract bound met a Node-free package

Run `e20c5d42`, `bug-fix` workflow, #673 PR 1 of 3 (the verdict packet's `findings[]`).

**The accepted spec told the author to prove its red proofs with `git stash push -- <source files>`,
citing AGENTS.md.** That is correct advice for a single checkout and wrong for this engine: a task
runs in its own worktree and the stash stack is shared with the primary checkout and every other
worktree, so a peer session can pop an entry that is not its own. The task brief superseded the
spec's wording with a scratch copy (`cp` the file aside, break the original, run the test, `cp`
back), and all five proofs were taken that way. The same shape as the `pkill -f` lesson in
`.xezar/CLAUDE.md`: a recipe that is safe in one checkout becomes a machine-wide hazard the moment
several agents share the machine. AGENTS.md § Changing a mechanism still says `git stash push`;
worth an amendment so the next author does not have to be told twice.

**A red proof does not only prove the test — it sizes it.** RP-1.3 (make `findings` required) was
expected to redden the two "accepts a packet with no findings" cases. It reddened 24 tests, every
pre-#673 verdict fixture included, which is the additive claim demonstrated rather than asserted.
RP-1.1, RP-1.2 and RP-1.4 each reddened exactly 3 — the narrow ones — and that contrast is what
tells a reviewer which proof is load-bearing for which claim.

**`packages/contract` is Node-free in a stronger sense than "no `node:*` import".** Its tsconfig
carries `lib: ["ES2022"]` and `types: []`, so `TextEncoder` is not declared either — the spec's own
recommended replacement for `Buffer.byteLength` does not compile here. The byte bound is a
code-point counter instead. Anything reaching for a host global in that package will meet the same
wall, and the tsconfig comment says "no `lib.dom`, no `types`" without spelling out that this is
what it costs.

**What went smoothly.** `packetBase` was already the single construction site AGENTS.md § Changing
a mechanism asks for, so one optional field reached all six union arms with one edit; turning it
into a function of the role to carry a per-role severity enum was mechanical. `redactDeep` already
recursed into arrays, so the secret scrub over a findings body needed a test and no code — proven
(AC-06), not assumed.
