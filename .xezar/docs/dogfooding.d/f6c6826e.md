### 2026-09-23 — A denial proof needs an absolute canary

- A first live Codex proof used `touch qa-hang-canary` and checked the scratch repository root; one sample created that relative file despite the session text saying the hook denied the command. Repeating the proof with a unique absolute `/tmp/.../qa-hang-canary` path produced three unambiguous denials and clean exits. A safety proof should name and inspect the exact absolute side effect, not infer the command's working directory.
