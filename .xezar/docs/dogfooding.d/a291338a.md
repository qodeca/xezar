### 2026-09-23 — The generated Codex schema answered what a dead account could not

- With the Codex account out of credits, `codex app-server generate-json-schema` under a throwaway `CODEX_HOME` was enough to build both Codex quota items without a model turn: it showed per-model buckets (`rateLimitsByLimitId` + `normalModelSlug`) exist, and that 0.156.0 has no `turn/failed` notification — a failed turn arrives as `turn/completed` with `turn.status: "failed"`, which the runner had been treating as an ordinary turn end (the #565 symptom).
- The schema does not carry the reset time of a `usageLimitExceeded` error; the Codex binary's own format strings (`%b %-d<suffix>, %Y %-I:%M %p`) did, and they showed the existing text parser would have read only the clock and guessed the day.
- Validating the hand-written fixtures against the generated schema with the repository's own `ajv` turned "schema-shaped" from a claim into a check. The live proof still waits for Codex credits.
