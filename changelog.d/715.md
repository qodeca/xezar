## 🐛 Fixes

- 🐛 **A project you remove while its folder-move refresh is still running is no longer
  re-registered behind you.** When a project's working copy moved and the cockpit rebuilt it, the
  clean-up that follows reads the project list and then re-registers the project under its new
  folder — and if you deleted the project from xezar in the moment between those two steps, the
  re-registration put it back. The deleted project stayed in the skills-update list and in the
  automation project map for the rest of the session, so xezar kept checking a folder it had been
  told to forget, until the next restart. The refresh now re-checks that the project is still live
  before re-registering it, and skips when it is not. Moving a folder and re-adding a project both
  behave exactly as before. (#715)
