Every row is **static-covered**; every live result is **not-run**. Coverage means the cited instruction addresses the expected decision, not that a model has followed it.

## Preserved controls audit

Static review also checked UI-only mutation against the narrow evidence-read exception; immutable active workflow definitions; required review distinct from hosting approval; two workflow returns versus two same-failure repairs; actual root lease and fixed fast-forward target; pause without automatic executor cancellation; baseline authority and explicit supersession; and checkpoint readback or disclosed conversation fallback. No polling or global-administration expansion was adopted.

Application tests and live Claude/browser execution were not run for this documentation revision. The checklist does not certify the future leader/MCP implementation.
